# Klugle Admin — distribution

Dépôt de **distribution** de l'extension WordPress Klugle Admin, composant de la
plateforme **Klugle Game Plateform**.

Il ne contient pas le code source du projet : uniquement le manifeste de mise à jour
lu par les installations existantes, et les archives d'installation attachées aux
[Releases](https://github.com/GregS1000RR/KGP-Admin-Release/releases).

| | |
|---|---|
| Manifeste | [`manifest.json`](manifest.json) |
| Paquets | onglet **Releases** |
| Éditeur | Klugle / Grenat Concept |

⚠️ Ce dépôt sert **uniquement** la plateforme Klugle Game Plateform (PRJ09). D'autres
projets Klugle embarquent des extensions portant le même nom mais un code différent :
ils ont leurs propres dépôts de distribution.
